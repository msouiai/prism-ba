# Fused fixed-system protocol

Registered 2026-09-14 before runs. Compare resident-device `memset(tacc)+Pass1+MFVinv` against point-owned fusion on identical captured arrays/vectors, holding compile-time FP32 compact2, damping, equilibration, stream, workspace, and math flags fixed. Test hard Muell then BAL captures in descending feasibility order: Final13682, Final4585, Final1936; memory failure alone advances to the next. Alternate after warmup, >=10 products/arm/repetition, >=3 repetitions. Freeze capture/outer/damping and SHA manifests before timing; probe seeds are 1701, 1702, 1703 with four vectors each.

The baseline is the compact2 point-CSR fixed-order Pass1, not the atomic observation kernel. Require finite expected-finite outputs/metrics. For point `u`, scale is `||u_ref||`; for bare-Schur `Sv`, term norm is `||Hcc v||+||W V^-1 W^T v||+||Sv_ref||`. Report absolute and relative errors (relative denominator is the corresponding nonzero reference-output norm, no `+1`), exact invalid-factor zeroing, and sampled symmetry defect `|x^TSy-y^TSx|/(||x||||Sy||+||y||||Sx||)`. A zero symmetry denominator passes only when its numerator is exactly zero. Acceptance is `error <= 1e-12*(1+term_norm)`, finite metrics, relative error <=1e-10 for nonzero tiny fixtures, and symmetry defect <=1e-12. Report CUDA-event chain/product wall and profiler bytes/atomics if available. Promotion requires >=5% median fixed-product gain on both captures; otherwise stop before native testing.
