# Brief 8 registration: conditional point-Newton witness screen

The Ladybug witness has concentrated point-model error; Final3068's raw reference failures are camera dominated. Test one conditional point-Newton step at the existing prescribed camera increments, before changing Schur assembly or running a new trajectory. This is the minimum model-fidelity gate, not proof of a full joint Newton solver.

For each point assemble the original Euclidean GN block V, gradient/conditional RHS and the exact residual Hessian term `N=sum r_k Hessian_X r_k` for SIMPLE_RADIAL with fixed k2=0. Use the same lambda and original-coordinate diagonal/trace damping as the Euclidean control. If the damped candidate V+N+lambda Dp is finite and positive definite in Dp-whitened coordinates (minimum eigenvalue >1e-12 times maximum absolute eigenvalue), use it. Otherwise use the unchanged damped GN block for that point. No eigenvalue tuning or additional floor. Report raw undamped indefiniteness and actual damped fallback separately, including point fractions and observation-weighted fractions.

Same nine captured states, both prescribed camera directions, N3 CPU repetitions (54 runs). No state/threshold choice from outcomes. Compare to the retained Euclidean conditional controls. Report original full objective, GN prediction, active hybrid prediction (with N omitted at fallback points), true decrease, both rho values, full initial-score parity, point-solve residuals, indefinite/fallback fractions, inward/outward displacement and CPU work. All scored observations retained. Validate analytic residual-Hessian contractions against differentiated analytic gradients/central differences on synthetic projections before witness evaluation; verify zero residual gives GN and fallback leaves the exact control system.

Kill if Ladybug model agreement does not improve with an accepted useful direction, if fallback exceeds 5% of points in the informative witness (record this as the brief's 'few percent' threshold), or if a >0.15% cost regression appears on a primary witness. A positive screen still needs native implementation and the common N3/N5 target grid before promotion. No tau sweep, mixed-precision factorization or objective change.

The camera-only prediction variant cannot rescue the already measured raw Final3068 proposals: every such proposal increases true cost, and changing pred alone leaves the mandatory descent check false. Record that algebraic kill rather than credit a relabelled rho as progress. A change to camera direction or retraction would be a different experiment. Newton/Hessian corrections have established prior art; no broad novelty claim from this screen.
