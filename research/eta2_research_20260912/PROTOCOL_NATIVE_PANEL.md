Native wall includes all new clustering, setup, assembly, metric work, scoring and transfers inside the solver. Process wall is separate.

For retry accounting, enable the same lightweight host steady-clock attempt trace on both derived arms. It adds no GPU barriers, buffers output until solver exit and records numeric-repair continuations too. Report failed-attempt seconds and retry-entry seconds separately, divided by summed attempt seconds and by full native wall where appropriate. Ordinary cost/dot synchronizations delimit actual GPU progress; this is host attempt accounting, not an exclusive kernel profiler. Count trace overhead in both arms. Check attempt acceptance and matvec totals against the solver's summary before using the fractions.

Report median/range crossing times only with the corresponding hit count, both signs of change, full costs, cap/stall exits, rejection counts, PCG per outer and algorithm events. The standing signal gate is >0.15% median objective difference or disjoint observed crossing-time ranges; N5 is an exploratory hit sample, not established population reliability. Do not promote with lost practical target reliability or >20% practical median-time regression. Apply each brief's additional kill rule. A combined model/metric arm cannot support attribution to only one ingredient.
