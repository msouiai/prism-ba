# D1 paired-inference substrate

Registered before using the paired design for an algorithm verdict.

Each pair shares one BAL input generated by `bal_perturb.py`.  Observations and
indices are copied byte-for-byte.  `k2` is fixed to zero.  Independent PCG64
Gaussian directions are normalised to unit RMS within rotation, translation,
focal, `k1`, and point-coordinate fields.  The registered dose for basin
pairing is `epsilon=1e-12`; geometry uses the median centred point radius,
focal uses median absolute focal length, rotation uses one radian, and `k1`
uses `max(median(abs(k1)), 1e-3)`.  Every generated input records its SHA256,
field scales, and independently evaluated initial residual-space distance.

Binary target hits use `PairedSprt(q0=.35, q1=.50, alpha=.05, beta=.05,
max_pairs=100)`.  Only discordant pairs change the likelihood.  Variant-only
hits support non-inferiority; control-only hits support harm.  Double hits and
double misses remain in the ledger.  The registered all-discordant boundaries
are nine consecutive variant wins for non-inferiority and twelve consecutive
control wins for harm.  Pair order, execution order, and concordant outcomes
must not change the likelihood.

This commit only validates the perturbation and inference machinery.  Every
algorithm comparison will separately register its fixed perturbation seeds,
continuous paired statistic, target/cap, arm order, and stopping rule before
native execution.
